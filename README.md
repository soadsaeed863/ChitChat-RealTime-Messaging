#  ChitChat: Real-Time Messaging App

Full-stack real-time chat app with direct messages and public/private group chats.

 **1st Place, Digital Egypt Pioneers Initiative (DEPI)**
 [Watch the Demo](https://drive.google.com/file/d/1W6-XqZDMrGmQCCPjQGt1ojz2AXyKSJJY/view?usp=drive_link)

##  Features
- Real-time messaging with WebSockets
- Direct and group chats (public & private)
- JWT authentication
- Real-time notifications
- Search and filter conversations
- Profile management (username, profile photo)
- Responsive design

## 🛠 Tech Stack
**Frontend:** React, Vite, Socket.io, Bootstrap, React Router
**Backend:** Node.js, Express.js, WebSockets, JWT

##  Run Locally
```bash
# Backend (create .env with PORT, JWT_SECRET, DB_URI)
cd backend && npm install && npm start

# Frontend
cd frontend && npm install && npm run dev
```
